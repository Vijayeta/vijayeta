## 🚀 What I'm Building

### [EnergySense AI](https://energysense-ai.vercel.app)
An AI energy consultant for India's underserved SMEs. Facility managers know their bills are high but can't afford ₹50,000–₹2,00,000 energy audits — this is zero-hardware, upload-and-go CSV analysis instead.

Built on a hybrid RAG architecture (Claude Sonnet 4.6 + Voyage AI) grounded in Indian tariff and BEE standards, with a self-enforced quality contract: an `evalAndFix` retry loop plus a 15-point regression suite.

Solo PM + builder — research, strategy, architecture, evals, and deployment.
